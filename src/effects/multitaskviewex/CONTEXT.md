# 多任务视图（multitaskviewex）领域词表

> 本文件只收录**领域术语**（业务语言），不含实现细节。实现决策见 `docs/adr/`。

## 分层
- **业务真相（business truth）**：工作区集合/顺序/当前索引/窗口↔格映射/预览态。只属于 Model。
- **稳态目标（steady-state target）**：Model 为每个 item 算出的「应当到达」的几何与显隐（位置/尺寸/透明度/占位）。由纯函数计算、可单测；是 Model 对 Scene 的唯一输出之一。
- **插值状态（interpolation state）**：节点的当前视觉值 current、过渡起点 from、目标 target、进度/时间线。只属于 Scene。
- **对齐（alignment）**：Scene 每收到 Model 事件，按「当前业务项集合」重组自己的节点集——仍在的项重设目标（from=current），消失的项转幽灵，新增的项建节点。事件本身无序，靠对齐而非逐事件补间合成动画。

## 交互与生命周期
- **幽灵节点（ghost node）**：被删除项留在 Scene 的临时节点，用最后一个视觉状态播完退场动画后销毁；不占 Model。
- **拖拽会话（drag session）**：拖拽期间 Model 持有被拖项、指针输入、方向与删除姿态，持续重算稳态目标；松手仅确认最终顺序，不触发新动画起点。
- **预览项（add preview）**：添加工作区的暂定条目（与正式条同类型）。生命周期（用户确认）：每次 **hover 进入**加号抽一张新随机壁纸并显示；**点击提交**用预览那张创建（预览 = 结果）并**重摇下一张**（连续创建每次不同）；**新项到达目标位置后**预览才刷新显示（避免与新项重叠）；**鼠标离开**即清除预览并取消待显示的刷新。

## 数据来源
- **工作区集合/编号**：KWin 内部（VirtualDesktopManager），唯一权威。
- **壁纸数据**：deepin daemon（DBus），仅承载壁纸 uri 的读写；删除工作区时由我们迁移（deepin 不会自迁移）。
